# My project

A React app built with [Halation](https://www.npmjs.com/package/@halation/react), Vite and TypeScript.

## Commands

- `pnpm dev` starts the app and reloads it as you save.
- `pnpm build` checks the types and builds the app into `dist`.
- `pnpm preview` serves the built app.
- `pnpm lint` checks `src` against Halation's rules.
- `pnpm check` measures the running page in light and dark mode.

Use `npm run` in place of `pnpm` if you installed with npm.

## Where things are

- `src/project.ts` holds the project's name and the phenomenon behind the opening section.
- `src/App.tsx` is the page. Start here.
- `src/app.css` lays the page out, using Halation's tokens.
- `AGENTS.md`, `CLAUDE.md` and `.claude/` set up coding agents to follow the same rules you do.
