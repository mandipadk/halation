# create-halation

Start a React project with Halation already in place.

```bash
npm create halation my-app
cd my-app
npm install
npm run dev
```

You get a Vite and React app with the Halation styles and components, an opening on a phenomenon, working examples, and an agent kit: the Halation skill, a hook that lints every file an agent edits, and an AGENTS.md other tools read too.
